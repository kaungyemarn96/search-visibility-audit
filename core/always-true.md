# Always true

Rules that hold in every bundle, every content type, every client. If a rule is only true for one kind of writing it does not belong here, it belongs in that bundle.

Each of these earned its place by failing somewhere first.

---

**Never invent a fact, figure, quote or date.** Source it, or mark it as a placeholder and say so. A number nobody can trace is worse than a gap, because a gap gets filled and a wrong number gets repeated.

**Never fill another team's gap on their behalf.** A missing figure is a recorded blocker with a named owner. An invented one is a reporting error that survives into next quarter.

**Never write a full piece in one pass.** Work section by section, closing each before starting the next. This is the rule three independent systems in the source corpus arrived at separately, which is why it sits here rather than in a bundle.

**Stop and ask before drafting when the gap is load-bearing.** Stop when the answer would change what you write; flag it and continue when it would not. The distinction between stopping and flagging is the single most transferable rule in this system.

**The canonical layer wins.** Once content moves there, the working copy is a draft of history. Which layer is canonical is set per client in `stack.md`.

**Mirror, never author, what another team owns.** Where a team writes its own material, the content function owns the structure, the pointer to the source, and the synced date. It does not write the technical content and does not fill its holes.

**Check a claim about the client's own estate against both layers before stating it.** Whether a document exists, how many there are, whether a cycle completed. If the two layers disagree, or only one was checked, say which.

**A rule is obeyed or switched off with the reason written down.** Silently ignoring a rule leaves the next person unable to tell a deliberate exception from a mistake.

**Every deliverable names who applies it.** Where the writer determines a value and someone else enters it, the work ends at a clean handover. See the `who applies changes` column in `stack.md`.

**Nothing automated fires without being asked.** Detection, monitoring and reporting run on a stated cadence. Automating the decision to act is a separate decision, never assumed.

---

## What is deliberately not here

Voice. Structure. Length. Vocabulary. Those change per surface and per client, so they live in the bundles and in the ban overlays. A rule that needs an exception for video, or for a report, or for a client in a regulated industry, is not always true.
